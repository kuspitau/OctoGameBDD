OctoGameDB initial repository bootstrap
====================================

Prepared: 2026-08-24

Purpose:
- Initial GitHub push before the first coding conversation.
- Contains architecture/project memory, workflow contract, Python skeleton, and test skeleton.
- Contains no large/raw game data and no gameplay implementation.

Recommended first push:
1. Extract this archive.
2. Optionally rename the project directory/repository before the first push.
3. From the project root:
   git init
   git add .
   git commit -m "Initial OctoGameDB project bootstrap"
   git branch -M main
   git remote add origin <YOUR_REPO_URL>
   git push -u origin main
4. Grant the next coding conversation read-only access to that repository.
5. Ask it to read `AGENTS.md` and continue from `docs/project/CURRENT_STATE.md`.

Initial local smoke validation:
  python -m venv .venv
  .venv\Scripts\activate
  python -m pip install -e ".[dev]"
  pytest

Large data:
- Do not add full dumps, client files, WDB/DBC archives, generated DBs, or scrape caches to Git.
- Use data/raw etc. locally and small tracked fixtures for coding-agent tests.
