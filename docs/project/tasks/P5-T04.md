# P5-T04 — pfquest-octo spawn membership divergence characterization

## Status

`READY_FOR_IMPLEMENTATION`

## Routing basis

P5-T03 is fully validated and measured:

```text
audited records                = 450659
same_value                     = 394970
different_value                =   2759
active_only                    =  32078
comparison_only                =  12600
not_directly_comparable        =   8252
```

The direct-value differences are concentrated in complete spawn sets:

```text
creature spawn_set different_value   = 1062
gameobject spawn_set different_value = 1508
total                                = 2570 / 2759 (93.15%)
```

Unique one-sided spawn memberships are:

```text
creature active-only / comparison-only   = 10255 / 3928
gameobject active-only / comparison-only =  5750 / 2362
total                                    = 22295
```

Shared spawn identities have zero `position different_value`, while only 21 shared
`respawn_seconds` facts differ.

This does **not** prove that all 22,295 one-sided memberships are literal additions/removals. Spawn
identity includes coordinate information, so a changed coordinate may appear as an active-only member
plus a comparison-only member.

P5-T04 must characterize this topology before any authority/policy decision.

## Goal

Add a deterministic read-only audit that explains the P5-T03 one-sided spawn membership population at
the unique spawn level.

The task should answer:

- which parent templates account for the one-sided memberships;
- which zones/maps account for them;
- how concentrated the differences are;
- how many parents contain only additions, only removals, or both;
- how active-side source/revision/selection policy is distributed;
- which active-only/comparison-only pairs within the same parent template and zone are plausible
  coordinate-relocation candidates;
- how much of the 22,295-member discrepancy remains genuinely one-sided after reporting relocation
  candidates;
- whether any bounded subset warrants a later source-authority or corrective task.

P5-T04 characterizes evidence. It does not merge identities or change selection.

## Relocation-candidate analysis

Because coordinate-bearing identity can turn a move into one removed + one added key, P5-T04 should
provide a **candidate** relocation analysis.

Constraints:

- only compare opposite-direction one-sided spawns within the same subject kind;
- require the same parent template;
- require compatible coordinate space and the same zone/map context;
- compute deterministic geometric distance when the coordinate semantics permit it;
- report distance bins and bounded nearest candidate pairs;
- do not automatically merge, rewrite, or declare two spawn identities equivalent;
- do not choose an arbitrary single threshold and call every match below it a true move.

Prefer reporting several deterministic distance bands, for example derived from the coordinate space,
so later evidence can choose a justified threshold.

If nearest-neighbor matching can be ambiguous, preserve ambiguity rather than greedily inventing
identity.

## Required aggregates

At minimum:

- total unique shared / active-only / comparison-only members;
- counts by creature/gameobject;
- counts by parent template;
- counts by zone/map;
- counts by active selected source/revision/policy;
- number of parents with active-only, comparison-only, and mixed membership;
- distribution of one-sided member counts per parent;
- relocation-candidate counts by distance band;
- number of one-sided members with zero, one, or multiple plausible opposite-direction candidates;
- top bounded parent/zone concentrations;
- deterministic drill-down rows for representative parents and relocation candidates.

The P5-T03 baselines that must reconcile exactly are:

P5-T04 must not count the paired `position` and `respawn_seconds` observation groups as two separate
membership differences.

## Closeout decision

P5-T04 closeout should route from measured evidence.

Possible outcomes:

1. most one-sided memberships reduce to plausible coordinate-relocation patterns:
   route a bounded coordinate/identity-semantics investigation;
2. differences are genuine additions/removals concentrated in clear Octo-specific regions/templates:
   route a bounded source-completeness/authority analysis for that subset;
3. differences are diffuse informational changes without stronger authority evidence:
   return to broader domain coverage/completeness auditing;
4. an importer/reconciler defect is found:
   route a corrective task before further policy analysis.

No authority or architecture decision is made by P5-T04 itself.
