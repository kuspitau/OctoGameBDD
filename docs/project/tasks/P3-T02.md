- unsupported indirect/runtime mutation fails closed instead of executing Lua.

The deterministic Turtle P3 revision hashes the exact bounded load/composition inputs above and the
loader validates the relevant TOC/XML/patchtable markers.

## Architecture decision — D-028

P3-T02 introduces two quest-specific complete-view facts:

```text
quest_presence
quest_endpoint_set
```

`quest_presence` means the composed source view has a usable enUS title for the quest.

`quest_endpoint_set` is the complete supported set of:

```text
endpoint_kind = giver | finisher
target_kind   = creature | gameobject
target_id     = native ID
```

Primitive `name` and `endpoint` evidence stays source-correct:

- inherited base facts remain `pfquest` observations;
- Turtle-patched primitive facts are `pfquest-turtle` observations.

The managed Turtle selection policy is:

```text
pfquest-turtle-effective-quests
```

Explicit/custom selections remain protected even if their selected observation still comes from the
`pfquest` source key.

A stale canonical endpoint is deleted only when its selected primitive relation is managed and the
selected complete endpoint set excludes it. Historical observations remain. Quest identity can be
removed for effective absence only when no protected selected support requires retention.

A Turtle-added title may activate a quest that P3-T01 skipped for missing base localization while
keeping inherited base endpoint provenance. Missing P1 endpoint targets remain unresolved evidence;
no placeholder creature/gameobject, spawn or geography is invented.

## Implementation

Added importer/reconciler:

```text
src/octogamedb/importers/pfquest_quest_overlay_reconcile.py
```

Key API:

```text
compute_pfquest_turtle_quests_revision(source_root)
reconcile_pfquest_turtle_quests(
    connection,
    pfquest_root=...,
    pfquest_turtle_root=...,
    pfquest_revision=...,
    turtle_revision=...,
)
```

The reconciler:

1. validates the Turtle quest load layout;
2. parses base and Turtle quest/localization tables without executing Lua;
3. applies supported direct overwrites and top-entry replacement/deletion;
4. requires a successful matching P3-T01 base quest import;
5. records base and Turtle complete-view evidence;
6. records source-correct primitive names/endpoints;
7. protects explicit/custom canonical selections;
8. synchronizes canonical quest identity and endpoint rows under D-028;
9. retains missing endpoint target evidence as unresolved rather than fabricating P1 identities;
10. is idempotent for the same revisions.
