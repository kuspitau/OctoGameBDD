## Purpose

`pfquest-octo` perform whole-entry replacement and all 1,085 raw replacement payloads differ.

other top-entry semantics systematically diverge as well.

## Exact set classification

For every fixed parent the audit reconstructs deterministic effective spawn sets:

```text

```

A/C is classified into exactly one of:

- `active_equals_comparison`;
- `active_strict_superset`;
- `comparison_strict_superset`;


## Interpretation and closeout

The decisive observation is not that active is always more complete. It is that source disagreement
is almost entirely a complete-spawn-membership disagreement:

- 99.908% of raw payload divergences are `spawn_membership_only`;
- A and C are equal for none of the fixed parents;
- A is a strict superset for 472 / 1,085 (43.50%);
- 613 / 1,085 (56.50%) are partial-overlap or disjoint;
- C is never a strict superset, but partial/disjoint parents retain comparison-only members;
- one parent also differs in non-spawn top-entry fields, which remains an explicit isolated outlier.

Consequently P5-T08 does **not** authorize:

- a global source promotion;
- treating Turtle and `pfquest-octo` as interchangeable enrichment sources;
- unioning their spawn sets into canonical truth;
- dropping comparison-only evidence;
- pairing/merging spawn identities by proximity;
- changing D-025 or D-026.

The source families require separate `spawn_set` semantics for this bounded world-view question.
Turtle remains the managed selected view under D-026, while `pfquest-octo` remains comparison evidence.

This is sufficient to close the current P5 world-source audit thread. Any later authority decision
must be driven by a concrete consumer requirement and preferably direct Octo-specific evidence, not by
repeating the same exact-set comparison.
