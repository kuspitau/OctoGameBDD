# P5-T05 — three-way base/Turtle/Octo spawn divergence attribution

## Status

`READY_FOR_IMPLEMENTATION`

## Routing basis

P5-T04 is fully validated and preserves the exact P5-T03 one-sided membership baseline:

```text
creature active-only / comparison-only   = 10255 / 3928
gameobject active-only / comparison-only =  5750 / 2362
total one-sided                          = 22295
```

P5-T04 showed that a global coordinate-relocation explanation is insufficient:

```text
zero compatible opposite        = 12103  (54.29%)
exactly one compatible opposite =  1539  ( 6.90%)
multiple compatible opposites   =  8653  (38.81%)
```

It also showed that 22,264 / 22,295 one-sided memberships belong to an active
`pfquest-turtle-effective-world` complete-set context, while only 31 belong to the base effective
selection.

The missing question is therefore not merely "which points are close?" but:

> For each one-sided spawn membership, which of the base, Turtle-active and Octo-comparison source
> views actually contains that exact key?

That three-way membership vector can attribute the direction of source-view change without inventing
spawn identity equivalence.

## Goal

Add a deterministic read-only audit that classifies every P5-T04 one-sided spawn membership against
three persisted source/effective views:

```text
B = pfquest base complete spawn set
A = active selected complete spawn set
C = pfquest-octo comparison complete spawn set
```

For the 22,295 members where `A != C`, the primary membership vectors are:

```text
B A C

1 1 0  -> comparison-side absence/change relative to base
0 1 0  -> active-side addition relative to base
1 0 1  -> active-side absence/change relative to base
0 0 1  -> comparison-side addition relative to base
```

The task should measure those four patterns exactly and explain where they concentrate.

P5-T05 is an attribution audit. It does not decide which source is globally authoritative.

## Secondary coordinate-change analysis

After source-side attribution is known, P5-T05 may reuse P5-T04 geometry to identify **source-local
replacement candidates** without asserting identity.

Useful pattern pairings within the same parent/geographic context include:

```text
Octo-side possible move:
  base_active_not_comparison  <->  comparison_only_vs_base

Turtle-side possible move:
  base_comparison_not_active  <->  active_only_vs_base
```

For these pair classes:

- report deterministic nearest distances;
- report mutual-nearest pairs separately when useful;
- preserve ties/ambiguity;
- use distance bands rather than one identity threshold;
- do not merge or rewrite spawn keys;
- do not call a candidate a proven move.

This secondary layer should answer whether the source-attributed add/remove patterns frequently form
tight replacement pairs.

## Important semantic constraints

- `spawn_set` membership is a **set of unique `spawn_key` values**.
- Repeated identical `spawn_key` payload rows must not invalidate a parent.
- Primitive `position` or `respawn_seconds` observation rows must not be double-counted as membership.
- Absence from one effective source view is source-view evidence, not universal game non-existence.
- Canonical D-025 geography may be used for grouping only.
- `pfquest-octo` remains comparison evidence under D-026 unless a later explicit decision changes it.

## Closeout routing

P5-T05 should route from the measured three-way attribution.

Possible outcomes:

1. most divergence is one overlay adding/removing content relative to base:
   route a bounded source-completeness/authority review for that source/subset;
2. many source-attributed add/remove pairs form tight same-source coordinate replacements:
   route a bounded coordinate-identity/source-normalization investigation;
3. divergence is concentrated in a small set of custom zones or parent families:
   route a bounded zone/content-source audit;
4. no dominant source-side pattern emerges:
   return to broader P5 coverage/completeness analysis.

No authority or architecture decision is made by P5-T05 itself.
