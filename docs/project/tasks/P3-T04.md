# P3-T04 — quest objectives and objective geography

**Status: VALIDATED**

## Goal and boundary

P3-T04 adds quest objective targets and the geography that can be derived from those primitive
targets. It deliberately does not invent objective quantities that the reviewed pfQuest objective
membership export does not carry.

The bounded source family is:

```text
obj.U   creature objective targets
obj.O   game-object objective targets
obj.I   item objective targets
obj.IR  quest -> item-use objective references
obj.A   area-trigger objective targets
obj.Z   direct zone/area objective targets
```

plus the supporting `quests-itemreq` item-use target contract and `areatrigger` location data.

Required-item quantities, guaranteed/choice rewards, item-started quest acquisition and broader quest
conditions remain outside this task.

## Source semantics established

### Objective membership

The exported `obj.U/O/I/IR/A/Z` arrays are membership lists. They do not carry objective quantities.
P3-T04 therefore preserves list membership, list presence/absence, explicit empty lists, source order
and duplicate diagnostics without promoting an inferred quantity.

### Item-use objective support

`obj.IR` is a quest -> item-use/reference membership relation. The separate `quests-itemreq` dataset
maps an item to signed target IDs plus spell IDs:

```text
positive target ID  -> creature
negative target ID  -> game object
absolute ID         -> native target identity
value               -> associated spell ID (numeric/string-normalized)
```

These are two layers, not one collapsed polymorphic relation:

```text
Quest -> item-use Item
Item  -> use target Creature/GameObject + spell
```

### Area-trigger support

`areatrigger` is a separate identity/location source. Location rows carry zone-percent coordinates
and a zone ID. Explicit empty coordinate lists are distinct from an absent area-trigger entry.

AreaTriggerID is not treated as ZoneID.

### Direct zone objectives

`obj.Z` is direct source-backed zone objective evidence. By contrast, creature/game-object objective
geography remains derived from target spawns. The validated real source revisions happen to contain
no selected `obj.Z` objective (`Z = 0`), but parser/schema/reconciliation/query behavior is covered by
fixtures.

### Turtle composition

Turtle `patchtable.lua` uses whole-entry replacement semantics; `_` deletes an entry. The objective
reconciler reuses the established quest compositor and applies separate complete-set policies for this
P3-T04 fact family. It fails closed if unsupported direct auxiliary `overwrites.lua` mutation of
`quests-itemreq` or `areatrigger` is introduced in a future source revision.

## Implemented schema

Migration `0009_quest_objectives.sql` adds explicit domain tables rather than a generic polymorphic
objective table:

```text
quest_objective_sets
quest_creature_objectives
quest_gameobject_objectives
quest_item_objectives
quest_item_use_objectives
quest_area_trigger_objectives
quest_zone_objectives

area_triggers
area_trigger_locations

item_use_target_sets
item_use_creature_targets
item_use_gameobject_targets
```

Complete-set rows preserve whether the selected source set is present and how many members the
selected set declares. Area-trigger and item-use support likewise preserve complete-set presence/count
semantics.

No missing quest/creature/gameobject/item/zone target is fabricated simply to satisfy a foreign key.

## Provenance and reconciliation

Task-specific complete-set facts are:

```text
quest_objective_set
area_trigger_location_set
item_use_target_set
```

Primitive objective/target/location observations remain separately attributable. Base and Turtle
selection policies are:

```text
pfquest-base-effective-quest-objectives
pfquest-turtle-effective-quest-objectives
```

The active Turtle effective view may supersede only task-managed/default selections. Explicit/custom
canonical selections remain protected. Stale managed materialization may be removed only when the
selected complete set excludes it; historical source observations are never deleted.

Deterministic source revisions include the exact source files relevant to base/Turtle quest
objectives, item-use support and area-trigger support.

## Query/read model

`quest_objectives_by_id()` and `quest_by_id()` expose:

- the declared complete objective set and source-shaped subtype lists;
- subtype/native target ID/name;
- resolution/unresolved state;
- selected complete-set and primitive provenance;
- creature/game-object spawn -> zone -> map geography;
- direct area-trigger coordinates and zone/map context;
- direct zone context for `obj.Z` when present;
- item-use target kind/ID/name/spell and its derived target geography;
- protected materialized extras outside a selected managed complete set when applicable.

Primitive facts remain distinguishable from derived geography.
