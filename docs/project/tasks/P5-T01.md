## Goal

Establish a deterministic, read-only audit baseline for the generic provenance resolution layer before
P5 changes any source-specific canonical-selection policy.

P5-T01 answers:

- how many observation groups have a canonical selection;
- how many remain unselected;
- how many groups contain competing distinct values;
- how many conflicts are resolved vs unresolved;
- how many unselected groups contain only one distinct value;
- whether any empty observation groups exist;
- which named selection policies currently choose canonical observations;
- which sources currently supply selected observations;
- how those counts break down by subject/fact family.

P5-T01 inventories the existing resolution state. It does **not** choose new winners.

## Implemented scope

- `resolution_report()` in the generic audit module;
- `python -m octogamedb resolution`;
- human-readable and deterministic JSON output;
- optional `--subject-kind` and `--fact` filters;
- aggregate selection/conflict/data-quality counts;
- selected-group/conflict counts by `selection_policy`;
- selected-group/conflict counts by selected `source_key`;
- group-state counts by `(subject_kind, fact_key, fact_kind)`;
- preservation of null `selection_policy` as JSON `null` / human `<none>`;
- regression coverage for existing `source`, `trace`, `conflict`, and `coverage` semantics;
- fixture/golden and CLI tests.

No migration, canonical mutation, automatic conflict resolution, source-priority change or UI work was
introduced.

## Report contract

`resolution_report()` returns:

```text
scope = provenance-resolution
subject_kind / fact_key filters
observation_group_count
selected_group_count
unselected_group_count
empty_observation_group_count
conflict_group_count
resolved_conflict_group_count
unresolved_conflict_group_count
unselected_single_value_group_count
selection_policies[]
selected_sources[]
fact_families[]
```

Conflict identity retains the P0-T03 rule: one observation group is a conflict only when it contains
more than one distinct canonical JSON `value_json`.

`unselected_single_value_group_count` is intentionally distinct from conflicts. It is an audit signal,
not authorization to select automatically.
