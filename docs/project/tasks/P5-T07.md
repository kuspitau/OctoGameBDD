## Required questions

For each fixed zone, answer deterministically:

1. How many addition members come from parents absent from base vs base-present parents?
2. How many distinct parent templates contribute?
3. On the active/Turtle side, how many relevant parents are:
   - inherited unchanged from base;
   - whole-entry replacements;
   - overlay-added parents?
4. On the pfquest-octo comparison side, what raw/composition mechanism produces its additions?
5. For base-present parents, what fraction of the selected/comparison complete spawn set is inherited
   base membership versus source-side added membership?
6. Which parent templates account for the largest addition counts in that zone?
7. For parent groups where both overlays add members, do the two raw sources:
   - add from the same parent family;
   - share exact raw coordinates/spawn keys;
   - add disjoint exact memberships;
   - use different whole-entry replacement payloads?
8. Are repeated raw coordinate rows/duplicate deterministic spawn keys materially contributing to
   the measured additions?
9. Which exact source files/top-level entries support representative examples?
10. Does the concentration reflect:
    - expected custom-zone content;
    - broader spawn-set enrichment of base content;
    - source-family divergence in complete-set construction;
    - or an unsupported/ambiguous raw-source behavior requiring narrower follow-up?

Question 10 is descriptive evidence only. It does not authorize source promotion.
