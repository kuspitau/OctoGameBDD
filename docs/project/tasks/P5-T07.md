## Raw-source classification contract

For each audited parent/source-side combination the implementation distinguishes:

```text
overlay_entry_inherited
overlay_parent_added
overlay_parent_removed
overlay_whole_entry_replaced
```

and retains explicit booleans for base data entry presence, base effective parent presence, patch
entry presence and effective parent presence.

For spawn membership it distinguishes/counts:

```text
member_inherited_from_base
member_added_by_overlay
member_removed_by_overlay
member_present_only_in_comparison
```

Composition uses the existing P1 source-native semantics: a patch value `"_"` removes the top-level
entry and any other patch table replaces the base top-level entry wholesale. Supported direct literal
`overwrites.lua` mutations are applied before composition. Unsupported indirect/runtime mutation is
rejected by the existing fail-closed P1 parser path; no recursive merge is inferred.

Repeated identical raw coordinate rows collapse to the existing deterministic `spawn_key` membership
semantics while remaining visible in duplicate diagnostics.
